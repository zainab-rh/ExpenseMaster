# Expense Master: JavaFX Management Suite

**Expense Master** is a desktop application developed for the **User Interface** course during the 2nd year of my Computer Engineering degree. The project focuses on creating a seamless user experience for tracking and managing personal finances efficiently.

---

##  Core Features
* **Full Expense Management:** Intuitive interface to Add, Edit, and Delete financial records.
* **Smart Categorization:** Organize spending into custom categories for granular tracking.
* **Visual Dashboard:** An integrated dashboard designed to help users visualize spending patterns at a glance.

## 🛠 Technical Stack
* **Language:** Java 17+
* **Framework:** JavaFX 17
* **Build Tool:** Maven 3.8.1+
* **UI Pattern:** Model-View-Controller (MVC)

---

##  Getting Started

### Prerequisites
Ensure your environment meets the following requirements:
1. **Java 17** or higher.
2. **Maven 3.8.1** or higher.
3. **JavaFX 17** (automatically handled via project dependencies).

### Installation & Execution
1. **Clone the repository:**
   ```bash
   git clone [https://github.com/zainab-rh/Expense-Master.git](https://github.com/zainab-rh/Expense-Master.git)
    ```

###  Execution Instructions
1. **Navigate to the project directory:**
   ```bash
   cd Expense-Master
   ```
   
2. **Launch the application:**
 ```bash
mvn javafx:run
```
